# Ideas de juego guardadas

- **pinball-circo.js** — «El gran pinball del circo» (flippers + bumpers-instrumento, Matter). Se descartó para
  *Secuencia de 3 Sonidos Diferentes* (2026-11-19): el niño no llega a ciertos puntos y un golpe equivocado
  reinicia, así que ganar dependía del azar. Reutilizable en un juego de reflejos donde no se pida un orden
  estricto (p. ej. puntuar por golpes, sin reinicio). Notas de física: lanzamiento ≈ 26 de velocidad en Matter 0.20 y el
  divisor del carril debe terminar más abajo que el arco superior.

- **radio-sintonizar.js** — «La radio mágica» (sintonizar un dial con estática, ojo mágico y osciloscopio). Descartada
  para *Secuencia de 3 Sonidos Diferentes* (2026-11-19) porque ya existe «radio del archivo» en
  `MemoriaAuditiva/ElSonidoRepetido` (girar el dial). No repetir.
