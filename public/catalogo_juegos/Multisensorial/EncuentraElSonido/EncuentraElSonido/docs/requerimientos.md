EDAD 3 – 4 AÑOS
Nombre del juego: ¿De dónde viene el sonido?

PANTALLA DE INICIO
Elementos visuales:
o	Escenario infantil, amplio y colorido
o	Zoe y Zeus como personajes guía
o	Dentro del escenario aparecen 3 elementos grandes y fácilmente reconocibles
o	Un botón grande de escucha representado únicamente mediante un icono
o	No aparecen instrucciones escritas
Audio de bienvenida
Zoe: ¡Escuchemos!
Zeus: ¿Dónde está el sonido?

MECANICA DEL JUEGO
El niño observa un escenario con tres posibles fuentes sonoras
El sistema reproduce el sonido de uno de los elementos
El niño debe encontrar visualmente el elemento que corresponde al sonido y tocarlo

Secuencia:
ESCUCHAR – BUSCAR – TOCAR EL ELEMENTO – RESPUESTA DEL SISTEMA

La ubicación de los elementos debe cambiar entre retos para evitar que el niño responda únicamente por posición.

RETO 1 - ¿DONDE ESTÁ EL PERRO?
Presentación

En el escenario aparecen:
1-	Un perro
2-	Un carro
3-	Un pájaro
El sistema reproduce un fuerte ladrido de perro

Acción del niño
El niño busca visualmente al perro y toca su imagen

Respuesta del sistema
Si acierta:
o	El perro realiza una pequeña animación
o	Se reproduce nuevamente un ladrido corto
o	Aparece una animación de celebración
o	Zoe dice:
¡Lo encontraste!

Si se equivoca:
o	El elemento seleccionado realiza una pequeña animación de intento
o	No aparece una señal negativa
o	Zeus dice:
¡Escucha otra vez!
El niño puede volver a escuchar el sonido

RETO 2 – ENCUENTRA LA TROMPETA
Presentación

Aparecen tres elementos:
1-	Una trompeta
2-	Una pelota
3-	Un gato
El sistema reproduce el sonido de una campana.

Acción del niño
Debe localizar la trompeta dentro del escenario y tocarla.

Respuesta del sistema
Correcta:
o	La trompeta aumenta y disminuye su tamaño y además suena
o	Aparece una pequeña animación de celebración
o	Zoe dice:
¡Sí! ¡Encontraste el sonido de la trompeta!
Incorrecta:
o	Permite volver a reproducir el sonido
o	Zeus dice:
¡Inténtalo de nuevo! Puedes lograrlo, escucha muy bien.

RETO 3 - ¿DONDE ESTÁ EL PAJARO?
Presentación
El escenario contiene:
1-	Un pájaro
2-	Un perro
3-	Una bicicleta
El sistema reproduce el canto de un pájaro

Acción del niño
Busca el pájaro y lo toca

Respuesta del sistema
Correcta:
o	El pájaro mueve las alas
o	Reproduce brevemente su canto
o	Zoe dice:
¡Lo encontraste!

Incorrecta
o	Permite volver a reproducir el sonido
o	Zeus dice:
¡Inténtalo de nuevo! Puedes lograrlo, escucha muy bien.

RETO 4 – ENCUENTRA EL SONIDO DE LA LLUVIA
Aquí se introduce una pequeña variación

Presentación
El escenario representa un espacio exterior con diferentes elementos:
1-	Un paraguas
2-	Una pelota
3-	Un árbol
El sistema reproduce el sonido de lluvia.

Acción del niño
El niño debe identificar visualmente el elemento relacionado con el sonido y tocar el paraguas

Respuesta del sistema
Al seleccionar correctamente:
o	Comienza una pequeña animación de lluvia
o	El paraguas se abre
o	Se escucha nuevamente la lluvia
o	Zeus dice:
¡Encontraste donde está! MUY BIEN

Al equivocarse
o	Permite volver a reproducir el sonido
o	Zeus dice:
¡Inténtalo de nuevo! Puedes lograrlo, escucha muy bien.

RETO 5 – ENCUENTRA EL SONIDO
Presentación
Se presenta un escenario con tres elementos nuevos
Por ejemplo:
1-	Un gato
2-	Un carro
3-	Una trompeta
El sistema reproduce uno de los tres sonidos.

Acción del niño
Debe escuchar, buscar y tocar la fuente correspondiente

Respuesta del sistema
Si acierta
o	Animación especial
o	Sonido de celebración
o	Zoe y Zeus celebran

Al equivocarse
o	Permite volver a reproducir el sonido
o	Zeus dice:
¡Inténtalo de nuevo! Puedes lograrlo, escucha muy bien.

RECOMPENSA FINAL
Al completar los cinco retos:
o	Zoe y Zeus realizan una animación de celebración juntos
o	Aparece una insignia visual de logro
o	Se reproduce un sonido de victoria
Audio ENCONTRASTE TODOS LOS SONIDOS – LO HICISTE MUY BIEN


EDAD 5 – 6 AÑOS
Nombre del juego: La ruta secreta de los sonidos

PANTALLA DE INICIO
Elementos visuales:
o	Escenario amplio dividido visualmente en diferentes zonas
o	Zoe y Zeus
o	Varias fuentes sonoras dentro del escenario
o	Botón de escucha
o	Sin instrucciones escritas
Audio
Zoe: Hola, Hoy tenemos una misión muy divertida
Zeus: Encuentra de donde viene el sonido
MECANICA DEL JUEGO
En cada reto:
1-	El niño observa el escenario
2-	El sistema reproduce un sonido
3-	El niño debe identificarlo
4-	Debe localizar visualmente su fuente
5-	Toca el elemento correspondiente
6-	El sistema valida la respuesta
7-	El escenario cambia para el siguiente reto
Diferencia importante
En este pueden aparecer 4 elementos en lugar de 3.

Los distractores deben ser mas parecidos entre si para aumentar la dificultad de búsqueda.

RETO 1 – LOCALIZA EL SONIDO
Presentación
Escenario con cuatro elementos
1-	Un perro
2-	Un gato
3-	Una bicicleta
4-	Una pandereta
El sistema reproduce el sonido de la pandereta

Acción del niño
Localizar la pandereta y seleccionarla

Respuesta del sistema
Correcta:
o	La pandereta se mueve
o	Se reproduce nuevamente su sonido
o	Zoe dice:
¡Encontraste el sonido correcto!

Incorrecta:
o	Se permite repetir el sonido
o	Zeus dice:
Escucha con mucha atención – Inténtalo de nuevo.

RETO 2 – SONIDOS EN DIFERENTES LUGARES
Presentación
Se crea un escenario dividido en diferentes zonas:
o	Parte superior
o	Parte inferior
o	Lado izquierdo
o	Lado derecho
En cada zona aparece una fuente sonora.

El sistema reproduce, por ejemplo, el sonido de una campana ubicada en la parte superior derecha.

Acción del niño
Debe localizar la campana dentro del escenario y tocarla

Respuesta del sistema
Al acertar:
o	La campana se ilumina
o	Se reproduce el sonido
o	Aparece una animación de confirmación
Zeus: ¡La encontraste!

RETO 3 – ENCUENTRA EL SONIDO ENTRE DISTRACTORES
Presentación
Aparecen cuatro elementos que pertenecen a una misma categoría

Ejemplo:
1-	Una campana
2-	Un triangulo
3-	Unas maracas
4-	Una pandereta
El sistema reproduce el sonido de las maracas.

Acción del niño
Debe discriminar el sonido y localizar las maracas

Respuesta del sistema
Correcta:
o	Las maracas realizan una animación
o	Se reproduce nuevamente el sonido
o	Zoe dice:
¡Muy buen oído!

RETO 4 – EL SONIDO VIAJERO
Este reto incorpora movimiento visual

Presentación
En el escenario aparecen diferentes personajes/objetos
El sistema reproduce un sonido asociado a uno de ellos
Después de un momento, el elemento cambia de posición dentro del escenario.

Acción del niño
El niño debe seguir visualmente el elemento y tocarlo cuando encuentre nuevamente la fuente del sonido.

Respuesta del sistema
Si selecciona correctamente:
o	El elemento se detiene
o	Se reproduce el sonido
o	Animación especial de acierto
Zeus: Lo seguiste, Muy bien

Si no selecciona correctamente
o	Debe repetir el ejercicio
Zoe: Inténtalo de nuevo, escucha muy bien, tu puedes lograrlo.

RETO 5 – MISIÓN FINAL ¿DONDE ESTÁ?
Presentación
Se presenta el escenario más complejo del juego:
o	5 elementos
o	Diferentes posiciones
o	Elementos visuales muy atractivos
o	Sin pistas escritas
El sistema reproduce un sonido

Acción del niño
Debe:
ESCUCHAR – IDENTIFICAR – BUSCAR – LOCALIZAR – TOCAR

Respuesta del sistema
Si acierta:
o	El elemento seleccionado se anima
o	Se reproduce nuevamente el sonido
o	Zoe y Zeus aparecen celebrando
o	Se activa la recompensa final

Si se equivoca:
o	Puede escuchar nuevamente
o	El sistema no elimina opciones
o	Se permite un nuevo intento

RECOMPENSA FINAL
Al superar los cinco retos:
Insignia visual EXPLORADOR DE SONIDOS
La insignia debe funcionar principalmente mediante una representación gráfica, no mediante lectura.

Audio final: LO LOGRASTE, ERES UN EXPERTO ESCUCHANDO
