EDAD 3 – 4 AÑOS

Nombre del juego: Los detectives de los sonidos

PANTALLA DE INICIO
Elementos visuales:
o	Escenario infantil relacionado con sonidos
o	Zoe y Zeus como personajes guías
o	Un elemento central que represente la escucha, por ejemplo, unas orejas, o un dispositivo sonoro
o	Botón grande de inicio representado únicamente con un icono.
Audio de bienvenida:
Zoe: ¡Hola! Hoy vamos a escuchar
Zeus: Presta mucha atención a lo que tus oídos hoy van a escuchar

MECANICA DEL JUEGO
La pantalla presenta:
o	Un botón grande de escuchar
o	Tres imágenes grandes como opciones de respuesta
o	Las imágenes deben ser claramente entre sí
o	No debe aparecer ningún nombre escrito debajo de las imágenes
o	El niño puede tocar nuevamente el botón para repetir el sonido.
Secuencia:
Escuchar – Observar las 3 imágenes – Elegir – Respuesta del sistema

RETO 1 – SONIDOS DE ANIMALES
Presentación
Aparecen tres imágenes:
1-	Perro
2-	Gato
3-	Pájaro

El sistema reproduce un ladrido de un perro.

Acción del niño
El niño toca la imagen del animal que corresponda al sonido.

Respuesta del sistema
Si acierta:
o	La imagen seleccionada se anima
o	Se reproduce nuevamente y brevemente el sonido
o	Aparece una animación de celebración
o	Zoe dice:
¡Sí!
Si se equivoca
o	No aparece una señal negativa
o	Se permite volver a escuchar
o	Zeus dice:
“Escucha otra vez”

RETO 2 – OTROS SONIDOS DE ANIMALES
Presentación
Aparecen tres imágenes:
1-	Vaca
2-	Gato
3-	Gallo

El sistema reproduce un maullido.

Acción del niño
Selecciona la imagen correspondiente

Respuesta del sistema
Correcta:
o	Animación del gato
o	Sonido brece de recompensa
o	Zoe dice:
¡Muy bien!
Incorrecta:
o	Permite repetir el sonido
o	Zeus dice:
¡Escucha bien!

RETO 3 – OTROS SONIDOS DE LA NATURALEZA
Presentación
Aparecen:
1-	Lluvia
2-	Mar
3-	Viento

El sistema reproduce el sonido de la lluvia.

Acción del niño
Selecciona la imagen que corresponde al sonido

Respuesta del sistema
Al acertar
o	Animación de lluvia
o	Sonido de celebración
o	Zoe dice:
¡Lo encontraste!

Respuesta Incorrecta:
o	Permite repetir el sonido
o	Zeus dice:
¡Escucha bien!


RETO 4 – SONIDOS DE OBJETOS
Presentación
Aparecen:
o	Una campana
o	Una pelota
o	Un carro

El sistema reproduce el sonido de una campana

Acción del niño
Selecciona la imagen correspondiente

Respuesta del sistema
Correcta:
o	La campana se mueve
o	Se reproduce su sonido lentamente
o	Zeus dice:
¡Si, eso es correcto!

Incorrecta:
o	Permite repetir el sonido
o	Zeus dice:
¡Escucha bien!

RETO 5 - ¿QUÉ SONIDO ESCUCHAS?
Presentación
Aparecen tres imágenes nuevas
Ejemplo:
1-	Pajaro
2-	Carro
3-	Perro
El sistema reproduce uno de los tres sonidos.

Acción del niño
El niño escucha y selecciona la imagen correspondiente.

Respuesta del sistema
Si acierta
o	Animación especial
o	Sonido de celebración
o	Zoe y Zeus celebran

FINAL DEL JUEGO
Al completar los cinco retos:
o	Aparece una animación de Zoe y Zeus celebrando
o	Se activa una insignia visual de detective
o	Sonido de celebración
o	El sistema registra el juego como completado.
Se reproduce un audio que diga
¡LO LOGRASTE!


EDAD 5 - 6 AÑOS

Nombre del juego: Los detectives de los sonidos

PANTALLA DE INICIO
Elementos visuales:
o	Escenario de misión auditiva
o	Zoe y Zeus
o	Elemento central relacionado con la escucha
o	Botón de inicio mediante un icono
o	Sin textos dirigidos al niño
Audio:

Zoe: Hola, Bienvenidos, hoy tenemos una misión
Zeus: Escucha con mucha atención

MECANICA DEL JUEGO
La dinámica tendrá diferentes niveles de dificultad

Nivel 1: Escuchar un sonido y relacionarlo con su imagen
Nivel 2: Diferenciar sonidos similares
Nivel 3: Recordar un sonido después de escucharlo
Nivel 4: Identificar un sonido dentro de una secuencia
Nivel 5: Resolver el desafío final de reconocimiento auditivo.

RETO 1 ¿QUÉ SONIDO ES?
Presentación
Aparecen tres imágenes

Ejemplo:
o	Perro
o	Gato
o	Pájaro
Se reproduce uno de los tres sonidos

Acción del niño
Selecciona la imagen correspondiente

Respuesta del sistema
Correcta:
o	Animación de acierto
o	Sonido de recompensa
o	Zoe:
¡Muy bien!

Incorrecta:
o	Puede volver a escuchar
o	Se permite un nuevo intento.

RETO 2 – SONIDOS SIMILARES
Aquí aumenta la dificultad auditiva

Presentación
Aparecen tres imágenes relacionadas con sonidos diferentes

Ejemplo:
1-	Campana
2-	Triangulo
3-	Tambor
El sistema reproduce uno de los tres sonidos

Los sonidos deben ser claramente distinguibles pero pertenecientes a la misma categoría sonora.


Acción del niño
Escucha atentamente y selecciona la imagen correspondiente

Respuesta del sistema
El sistema valida la selección y entrega una retroalimentación inmediata.

RETO 3 – ESCUCHA Y RECUERDA
Presentación
No aparecen inmediatamente las opciones

Primero:
Sonido – Pausa – Aparecen las opciones

El sistema reproduce un sonido
Después de aproximadamente dos segundos aparecen tres imágenes

Acción del niño
El niño debe recordar el sonido y seleccionar la imagen correspondiente

Respuesta del sistema
Correcta
o	Animación de celebración
o	Zoe:
¡Lo recordaste! MUY BIEN
Incorrecta
o	Se permite una segunda escucha.

RETO 4 - ¿QUÉ SONIDO FALTA?
Presentación
El sistema reproduce una pequeña secuencia de tres sonidos

Ejemplo:
PERRO – CAMPANA – PAJARO

Posteriormente reproduce:
PERRO – PAUSA – PAJARO

Aparecen tres imágenes
1-	Campana
2-	Gato
3-	Carro

Acción del niño
El niño debe identificar qué sonido falta y seleccionar la imagen correspondiente
Respuesta del sistema
Si selecciona correctamente:
o	Se reproduce nuevamente la secuencia completa
o	Se destaca visualmente el sonido que faltaba
o	Zeus dice:
Encontraste el sonido que faltaba ¡MUY BIEN!

RETO 5 – LA MISION FINAL
Presentación
El sistema reproduce un sonido sin mostrar las opciones inicialmente
Después de escucharlo aparecen tres imágenes
Pero esta vez los distractores son mas relacionados entre sí uno del otro.

Ejemplo:
1-	Lluvia
2-	Mar
3-	Viento
Se reproduce un sonido de lluvia

Acción del niño
Debe identificar el sonido y seleccionar la imagen correspondiente

Respuesta del sistema
Correcta:
o	Animación especial
o	Zoe y Zeus celebran
o	Sonido de victoria

Incorrecta:
o	Se permite repetir el sonido
o	El sistema ofrece un segundo intento.

RECOMPENSA FINAL
Al superar los cinco retos:
o	Animación especial Zoe y Zeus
o	Elementos visuales de celebración
o	Insignia: ERES UN EXPERTO EN SONIDOS
NOTA: Esta insignia debe ser visual, sin necesidad de texto para que el niño pueda comprender que ganó, el nombre puede quedar como identificación interna del sistema.

Audio Final MISIÓN CUMPLIDA – APLAUSOS
