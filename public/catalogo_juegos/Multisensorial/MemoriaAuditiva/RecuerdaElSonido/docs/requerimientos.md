EDAD 3 – 4 AÑOS
Nombre del juego: Los sonidos escondidos

PANTALLA DE INICIO
Elementos visuales:
o	Zoe y Zeus
o	Un escenario infantil con diferentes elementos sonoros
o	3 elementos grandes y reconocibles
o	Un botón de escucha
o	Un espacio central donde se desarrolla el desafío
o	No se utilizan palabras escritas para el niño.
Audio de bienvenida:
Zoe: ¡Escucha muy bien!
Zeus: ¡Vamos a recordar los sonidos!

MECANICA DEL JUEGO
El sistema reproduce uno o varios sonidos
Después de que el sonido termina, desaparece la pista sonora y el niño debe recordar lo que escuchó

La dificultad aumenta progresivamente.

Secuencia general:
ESCUCHAR – RECORDAR – OBSERVAR – ELEGIR – VALIDACIÓN

RETO 1 - ¿QUÉ ESCUCHASTE?

Presentación
Aparecen tres imágenes:
o	Tren
o	Trompeta
o	Manos en posición de aplaudir
El sistema reproduce el sonido de aplauso

Después de terminar el sonido, aparece nuevamente la pantalla con las tres opciones.

Acción del niño
Debe tocar el animal cuyo sonido acaba de escuchar

Respuesta del sistema
Correcta:
o	Las manos realizan la simulación del aplauso
o	Se reproduce brevemente el sonido de varios aplausos
o	Zoe dice:
¡Muy bien! Lo recordaste

Incorrecta:
o	Se permite escuchar nuevamente
o	Zeus dice:
¡Escucha otra vez!

RETO 2 – RECUERDA DOS SONIDOS

Presentación
El sistema reproduce:
Botellas con semillas – Pollito
No se muestran las opciones mientras se reproducen los sonidos

Cuando termina la secuencia aparecen tres imágenes
o	Campana
o	Botellas con semillas
o	Pollito

Acción del niño
El sistema pregunta mediante audio:
Zoe:
¿Cuáles escuchaste?
El niño debe seleccionar los dos sonidos que recuerda.
En este reto no importa el orden, sino recordar cuales sonidos estuvieron presentes.

Respuesta del sistema
Si selecciona correctamente los dos:
o	Ambos elementos se iluminan
o	Se reproducen nuevamente los dos sonidos
o	Animación de celebración.

RETO 3 ¿QUÉ SONIDO SE REPITIÓ?

Presentación
El sistema reproduce:
Pollito – Campana – Pollito

Después aparecen tres imágenes:
o	Perro
o	Campana
o	Pollito

Acción del niño
Debe identificar cual sonido escuchó dos veces

Respuesta del sistema
Al seleccionar el pollito:
o	El pollito realiza dos pequeñas animaciones
o	Se reproduce su sonido varias veces
o	Zeus dice:
¡Sí! ¡Lo escuchaste dos veces!

RETO 4 - ¿QUÉ SONIDO DESAPARECIÓ?

Presentación
Primero el sistema reproduce tres sonidos

Pasos de pies – Caballo galopear – Agujas de reloj

Después realiza una segunda reproducción:

Pasos de pies – Agujas de reloj

Acción del niño
Aparecen las tres imágenes y debe identificar qué sonido ya no está

Respuesta del sistema
Si selecciona al caballo:
o	El caballo realiza el movimiento como si galopeara
o	Zoe dice: ¡El sonido desapareció!

RETO 5 – RECUERDA EL SONIDO

Presentación
El sistema reproduce un sonido

Después aparece una escena con tres elementos diferentes

Ejemplo:
Sonido: vaca

Opciones:
o	Burro
o	Caballo
o	Elefante

Acción del niño
Debe recordar lo que escuchó y seleccionar la fuente correspondiente

Respuesta del sistema
Al acertar:
o	Animación especial
o	Sonido de celebración
o	Zoe y Zeus celebran

RECOMPENSA FINAL
Al completar los cinco retos:
INSIGNIA VISUAL DE LOGRO
Animación de celebración.

Audio: ¡Tienes muy buena memoria para los sonidos!

EDAD 5 – 6 AÑOS

Nombre del juego: El archivo secreto de los sonidos
En este nivel el niño debe retener información auditiva durante más tiempo y utilizarla para resolver diferentes desafíos de memoria-

PANTALLA DE INICIO
Elementos visuales:
o	Zoe y Zeus
o	Un escenario de archivo o centro de sonidos
o	Diferentes elementos sonoros
o	Botón de reproducción
o	Espacio central para presentar los desafíos
o	Sin instrucciones escritas.
Audio:
Zoe: ¡Guarda estos sonidos en tu memoria!
Zeus: ¡Después tendrás que recordarlos!

MECANICA DEL JUEGO
El niño escucha una información sonora

Después de finalizar, el sistema retira la información auditiva y presenta un desafío relacionado con lo que acaba de escuchar.

No siempre tendrá que repetir el sonido.

Puede tener que:
o	Recordar que escuchó
o	Identificar que sonido se repitió
o	Detectar cual desapareció
o	Reconocer qué sonido cambió
o	Recordar varios sonidos.

RETO 1 – RECUERDA LOS SONIDOS

Presentación
El sistema reproduce:
Pato – León – Rana

Después desaparecen los sonidos

Aparecen cinco opciones
o	Perro
o	Rana
o	Pato
o	León
o	Carro

Acción del niño
Debe seleccionar los tres sonidos que escuchó
El orden no es necesario en este reto

Respuesta del sistema
Si selecciona correctamente los tres:
o	Los tres elementos quedan marcados
o	Se reproducen nuevamente
o	Zoe dice: ¡Muy bien! Los recordaste

RETO 2 – EL SONIDO REPETIDO

Presentación
El sistema reproduce:
Caballo – León – Campana – Caballo
Después aparecen cuatro opciones.

Acción del niño
Debe identificar cual sonido apareció dos veces

Respuesta del sistema
Al seleccionar correctamente:
o	El elemento realiza dos animaciones
o	Se reproduce dos veces
o	Zeus dice: ¡Exacto! Ese sonido se repitió.

RETO 3 ¿QUÉ CAMBIÓ?
Este reto aumenta la dificultad

Primera reproducción
El sistema reproduce:
Tambor – Campana – Pájaro

Segunda reproducción
El sistema reproduce:
Tambor – Gaita – Pájaro

Acción del niño
Debe identificar que sonido cambió

Aparecen las tres opciones
o	Tambor
o	Campana
o	Gaita
o	Pájaro
Debe seleccionar el elemento que corresponde al cambio.

Respuesta del sistema
Correcta:
o	Campana y gaita aparecen visualmente relacionadas como antes/después
o	Se reproducen ambos sonidos
o	Zoe dice: ¡Descubriste el cambio!

RETO 4 – ¿QUÉ SONIDO CAMBIA?

Primera secuencia
Perro – Campana – Pájaro – Tambor

Después el sistema reproduce nuevamente la secuencia, pero omite uno
Perro – Campana – Tambor
Acción del niño
Debe identificar cual sonido escuchó anteriormente pero ahora desapareció

Respuesta del sistema
Si selecciona correctamente el pájaro
o	Aparece una animación
o	Se reproduce el sonido del pájaro
o	Se reproduce la secuencia completa
o	Zeus dice: ¡Encontraste el sonido perdido!

RETO 5 – EL GRAN DESAFÍO DE MEMORIA

Presentación
El sistema reproduce una secuencia de 5 sonidos diferentes

Ejemplo:
Pájaro – Tambor – Campana -  Perro – Pelota

Después de reproducirla, los sonidos desaparecen

Desafío
El sistema presenta diferentes opciones y realiza una pregunta mediante audio

Zoe: ¿Qué sonidos escuchaste?
El niño debe seleccionar los elementos que estuvieron presentes.

Después aparece una segunda pregunta:

Zeus: ¿Cuál escuchaste primero?
El niño debe seleccionar el sonido inicial

Finalmente
¿Cuál escuchaste al final?
Debe seleccionar el ultimo sonido

Respuesta del sistema
Para superar el reto debe resolver correctamente los tres desafíos.

Al completar:
o	Se reproduce la secuencia completa
o	Animación especial
o	Zoe y Zeus celebran

RECOMPENSA FINAL
INSIGNIA VISUAL: GUARDIAN DE LA MEMORIA AUDITIVA
Audio final:
Zoe: ¡Recordaste todos los sonidos!
Zeus: ¡Tu memoria auditiva es increíble!
