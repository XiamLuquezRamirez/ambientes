EDADES 3 - 4 AÑOS.
Nombre del juego: Los nidos mágicos de las vocales
Mecánica principal: descubrir, observar y emparejar vocales iguales.
PANTALLA DE INICIO
Escenario: Un jardín mágico donde cinco nidos esperan recibir parejas de vocales. Algunas vocales están escondidas bajo hojas grandes y coloridas.
Elementos visuales:
-	Zoe y Zeus como personajes guía
-	Cuatro tarjetas grandes, colocadas boca abajo
-	Dos parejas de vocales iguales por partida
-	Hojas animadas que cubren las tarjetas
-	Un indicador visual de avance mediante flores que se abren
-	Efectos de sonidos suaves y alegres.
Las vocales aparecen en minúscula, con una tipografía clara y consistente. No hay palabras ni instrucciones escritas para el niño.

Audio de bienvenida:
Zoe: ¡Hay vocales escondidas en el jardín!
Zeus: ¡Encuentra las que son iguales!

MECANICA DEL JUEGO
El niño toca una tarjeta para descubrir la vocal que contiene. Después toca otra tarjeta para intentar encontrar la misma vocal.

Si las dos vocales son iguales, las tarjetas permanecen descubiertas y se activa una animación. Si son diferentes, vuelven a ocultarse después de una pausa breve.

Secuencia:
TOCAR UNA TARJETA – DESCUBRIR LA VOCAL – TOCAR OTRA – COMPARAR – ENCONTRAR LA PAREJA

Para tener en cuenta:
-	Utilizar únicamente cuatro tarjetas en esta versión inicial
-	Incluir dos parejas de vocales por partida
-	Las tarjetas deben ser grandes y fáciles de tocar
-	La primera tarjeta permanece visible mientras el niño selecciona la segunda
-	Las tarjetas descubiertas correctamente ya no se pueden volver a seleccionar
-	El juego no debe depender de la lectura ni de la memoria de palabras.

RETO 1 – DESCUBRE LA PRIMERA PAREJA

Presentación
El niño toca una tarjeta y descubre la vocal. Luego selecciona otra para buscar su pareja.

Respuesta del sistema
Si encuentra dos vocales iguales:
-	Las tarjetas permanecen descubiertas
-	La vocal realiza una pequeña animación
-	Una flor del jardín se abre
-	Zoe dice: ¡Encontraste la pareja, Muy bien!

Si las vocales son diferentes:
-	Ambas tarjetas permanecen visibles brevemente
-	Después vuelven a ocultarse
-	Zeus dice: ¡Vamos a buscar otra!

El niño puede continuar sin perder el progreso.

RETO 2 – UNA NUEVA PAREJA

Presentación
Correcta:
-	Las dos vocales se iluminan
-	Aparecen pequeñas mariposas
-	La segunda flor del jardín se abre.

Incorrecta:
-	Las tarjetas vuelven a ocultarse después de una pausa breve
-	Se permite seguir jugando.

RETO FINAL – EL JARDÍN FLORECIDO

Presentación
Aparecen cuatro tarjetas con dos parejas nuevas, por ejemplo, i e i y a y a, distribuidas aleatoriamente.

Acción del niño
Debe encontrar ambas parejas tocando las tarjetas.

Respuesta del sistema
Al completar las dos parejas:
-	Todas las tarjetas quedan descubiertas
-	Las flores del jardín se abren simultáneamente
-	Zoe y Zeus celebran el resultado.

RECOMPENSA FINAL
Insignia visual: una flor mágica con dos vocales iguales en el centro.
Audio final:
¡Encontraste todas las parejas!
El sistema registra el juego como completado.




EDADES 5 - 6 AÑOS.
Nombre del juego: El castillo de los espejos secretos
Mecánica principal: memorizar posiciones, comparar vocales y encontrar parejas con mayor autonomía.

PANTALLA DE INICIO
Escenario: Un castillo fantástico con espejos mágicos y puertas cerradas. Cada pareja de vocales encontrada permite encender una luz del castillo.

Elementos visuales:
-	Zoe y Zeus como personajes guía
-	Ocho tarjetas boca abajo
-	Cuatro parejas de vocales iguales
-	Espejos que se iluminan al encontrar una pareja
-	Un indicador de progreso mediante cuatro luces
-	Animaciones de descubrimiento y celebración.
No aparecen instrucciones escritas dirigidas al niño.

Audio de bienvenida:
Zoe: ¡El castillo guarda parejas secretas!
Zeus: ¡Descubre las vocales iguales y abre sus puestas!

MECANICA DEL JUEGO
El niño debe descubrir dos tarjetas en cada turno y encontrar las que contienen la misma vocal. Las posiciones se mantienen estables durante la partida, para que pueda recordar donde vio cada letra.

Secuencia:
DESCUBRIR – OBSERVAR – RECORDAR – COMPARAR – EMPAREJAR.

Criterios para sistemas:
-	Presentar ocho tarjetas que contienen cuatro parejas
-	Usar las cinco vocales a lo largo de distintas partidas
-	Aleatorizar la distribución al iniciar cada partida
-	Mantener las posiciones fijas durante una partida
-	Ocultar las tarjetas que no forman pareja
-	Mantener descubiertas las parejas correctas
-	No incluir cronómetros obligatorios ni penalizaciones por equivocarse.

RETO 1 – LOS PRIMEROS ESPEJOS

Presentación
Aparecen ocho tarjetas boca abajo. Debajo se distribuyen cuatro parejas de vocales, por ejemplo, a, e, i y o, cada una repetida dos veces.

Acción del niño
El niño selecciona dos tarjetas por turno para descubrir sus vocales y determinar si son iguales.

Respuesta del sistema
Si encuentra una pareja:
-	Ambas tarjetas permanecen visibles
-	El espejo correspondiente se ilumina
-	Se activa un efecto sonoro de acierto
-	Zeus dice: “Una pareja encontrada”

Si no coinciden:
-	Ambas tarjetas se muestran durante un breve intervalo
-	Luego vuelven a ocultarse
-	Las posiciones se conservan para facilitar el recuerdo.

RETO 2 EL ESPEJO CAMBIANTE

Presentación
Se inicia una nueva partida con ocho tarjetas y cuatro parejas. Las posiciones cambian con respecto a la partida anterior.

Acción del niño
Debe recordar las vocales descubiertas y utilizar esa información para encontrar las parejas.

Respuesta del sistema
-	Cada pareja correcta enciende una luz del castillo
-	Cada error permite continuar
-	Las tarjetas permanecen en sus posiciones originales durante la partida.

RETO 3 – LA CAMARA DE LAS CINCO VOCALES

Presentación
Se muestran diez tarjetas que contienen cinco parejas: a, e, i, o y u.

Acción del niño
El niño debe encontrar las cinco parejas, seleccionando dos tarjetas por turno.

Respuesta del sistema
Correcta:
-	Las dos vocales quedan descubiertas
-	Se ilumina una plataforma
-	Se reproduce una animación breve

Incorrecta:
-	Las tarjetas vuelven a ocultarse
-	El juego continua sin perder las parejas ya encontradas.

RETO FINAL – ABRE EL CASTILLO

Presentación
El sistema presenta una última partida de diez con cinco parejas. Las posiciones se distribuyen aleatoriamente.

Acción del niño
El niño utiliza la memoria visual para localizar las parejas de vocales iguales hasta descubrirlas todas.

Respuesta del sistema
Al encontrar todas las parejas:
-	Los cinco espejos se iluminan
-	Se abren las puertas del castillo
-	Zoe y Zeus celebran la victoria.

RECOMPENSA FINAL

Insignia visual: una llave mágica rodeada por las cinco vocales.

Audio final:
¡Encontraste las parejas secretas del castillo!

El sistema registra el juego como completado.
